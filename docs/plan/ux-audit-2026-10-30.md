# UX audit 2026-10-30 — verified findings and plan

Source: an adversarial browser audit (v2.0.16 binary, Chromium, axe-core, deltaglider.com).
Every claim below was re-checked against the code at `06395b4d` and the running instance.
Claims that did not hold are listed at the end, so nobody fixes them.

## The one finding that matters most

Delta eligibility is a hardcoded extension list (`src/deltaglider/file_router.rs`):
`zip tar jar war ear dmg iso sql dump bak backup`. Nothing else is ever delta-encoded.

The README (line 52) promises savings for "media/texture variants, AI model variants, firmware,
ML checkpoints". None of `.bin .img .raw .safetensors .gguf .onnx .ckpt .pt .exe .dll .so .wasm`
is eligible, and no setting changes that. A first test with real firmware or model weights
stores every byte, and the inspector says "delta compression does not apply to this file type",
with no reason and no way out. The ratio gate already protects storage (a poor delta falls
back to passthrough), so a wider list costs codec CPU, not bytes.

## Plan

Phases are ordered by value. Each phase fixes the class and adds the guard.

### P0 — Things that are false today (small, ship first) — DONE 9310b2ce

1. Marketing numbers: "N,NNN% smaller" (ratio × 100) is the site's golden rule
   (`22ec4ce8`, `pricing.ts`), so it stays. Only "8,600% less" broke the rule: now "smaller".
2. `extractSummary`: drop the backticks of a code span, keep its content; strip `*_` only
   outside code. Unit tests: `` `/_/api/admin/*` ``, `` `config_sync_bucket` ``.
3. Upload copy names the file-type groups and says other files are stored whole (static:
   the upload page also serves non-admins, who cannot read the config).
4. Password button: a normal primary button. Guard: extend `contrast.test.ts` with
   text-on-fill pairs for every accent, and an ESLint rule against inline
   `background:` on AntD `Button`.
5. Theme: the pre-paint script sets `class` and `data-theme` from one value; `index.html`
   carries neither.

### P1 — Delta eligibility matches the promise — DONE

1. Broaden the default list with uncompressed binary formats (`bin img raw safetensors gguf
   onnx ckpt exe dll so wasm`, …). Compressed formats stay out (`.tar.gz`, `.deb`, `.rpm`,
   media). Measure each class with the codec bench before it goes in.
2. Per-bucket override in YAML (`storage.buckets.<b>.compression.extensions: {add, remove}`),
   shown in the bucket card.
3. Record why an object is passthrough (`not-eligible` / `ratio` / `compression-off` /
   `too-small`) in metadata, and say it in the inspector with a link to the bucket setting
   and to `explanation/delta-compression.md`.
4. Align README line 52 and the marketing feature list with what the router does. (Now true.)
5. Found while building it: an eligible object above `max_object_size` was refused on the
   copy, replication, lifecycle and CLI paths but stored whole by multipart. One rule now
   (`StorePlan::tries_delta(.., fits_delta_limit)`): it is stored whole on every path.
   Item 3 is done without a new metadata field: the inspector derives the reason from the
   bucket policy (`passthroughReason.ts`).

### P2 — The object browser works for keyboard and screen-reader users — item 1 DONE

Found while building item 1: every body-row style in `theme.css` named `tr > td`, and the
browser's virtual table draws `div` rows, so the cursor, hover and selection had no style at
all. That, not a missing feature, is why the audit called the cursor "hidden". Also: with a
cursor row, Enter on a focused button opened the row (now `isActivatableTarget`).

1. `ObjectTable`: ARIA grid (`role=grid/row/gridcell/columnheader`, `aria-rowcount` +
   `aria-rowindex` for the virtual rows, `aria-sort`, roving `tabindex` that follows the
   existing ↑/↓ cursor, `aria-selected`). Vitest dom tests; axe in `scripts/qa-e2e.sh`.
2. Below 720 px: a card list (name, size, storage type); above, the name column takes the
   rest after fixed data columns with a max width.
3. `FormField` owns the error state (`aria-invalid`, `aria-describedby` to the message).
4. Sidebar entries become `<a href>` with a click handler (keeps `usePathRouter`).
5. Guard: a Playwright pass that fails on axe serious/critical and on targets < 24×24 for
   every `ADMIN_IA` leaf and the browser, in both themes.

### P3 — One type scale, one status palette

0. Measured: Manrope's space is 2 px at 12 px in Chromium (digits 7 px): "1h 38m ago" reads
   "1h38mago". Add `word-spacing` for the UI font at small sizes, or pick another UI face.
1. Tokens: 6 sizes (11, 12, 13, 15, 20, 28) and two families (UI, mono for data only).
   ESLint refuses numeric `fontSize` literals outside the token file; migrate panel by panel.
2. Status colours: delta/reference = success colour, original = neutral. Same in the
   inspector, bucket card and analytics.
3. Inspector: the folder figure (incl. the shared baseline) is the headline; the per-file
   figure is the detail line.

### P4 — Copy

1. Every "go to X" in copy is a link (`System → Backup` jumps to the card). Grep for `→` in
   UI strings; a source test refuses an arrow path in a string without a link.
2. Prose budget in forms: one sentence of help; the rest moves to a "Learn more" link to the
   docs anchor. Start with Event delivery, Lifecycle, Replication, Credentials.
3. Audit page names where the durable trail is (stdout / JSON logs).
4. One noun for objects in the browser ("objects", never "items").

### P5 — Weight

1. Render mermaid to SVG at build time for both surfaces (docs are already in the binary);
   drop mermaid, cytoscape and katex from the runtime bundle.
2. Check the antd chunk for whole-library imports; split admin panels per route.

### P6 — Command palette everywhere

`Ctrl+K` in the browser too: buckets, folders in view, settings pages, recent objects.

## Audit claims that did NOT hold (do not fix)

- "Share has one fixed expiry" — 1 h / 24 h / 7 days exist (`InspectorPanel.tsx:22`).
- "`Ctrl+,` has no handler" — it opens Settings (verified in the browser).
- "The shortcuts modal lies about `Ctrl+K`" — it lists it under "Settings — command palette".
- "Generate buttons are unlabeled" — they carry `title` ("Generate random key"); icon-only,
  but named.
- "Banner pastes `access.iam_mode: gui` into the sentence" — it is a separate code chip.
- "The firmware example in the docs fails" — the docs use `.tar`, which works. The README
  promise (above) is the real gap.
- "Four page widths" — two by design (`CONTENT_FORM` / `CONTENT_WIDE`); not re-measured.
